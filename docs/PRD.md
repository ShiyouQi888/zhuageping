# 本地截图软件 PRD

## 1. 产品概述

产品名称：抓个屏

作者：齐世有

联系邮箱：blacklaw@foxmail.com

产品定位：一款面向 Windows 的纯本地截图工具，支持截图、时间戳、地点设定、水印、标注、历史管理和本地导出，不依赖云端服务。

核心价值：

- 快速完成全屏、窗口、区域截图。
- 自动叠加本地时间戳和用户设定地点。
- 图片、配置、历史记录全部保存在本机。
- 支持面向工作留痕、巡检、报销、客服、教学、项目记录等场景的资料整理。

## 2. 目标用户

- 现场巡检、工程、物业、施工记录人员。
- 客服、售后、远程协助人员。
- 财务、行政、报销凭证整理人员。
- 教师、培训师、内容创作者。
- 需要本地留痕但不希望图片上传云端的个人或团队。

## 3. 设计原则

- 本地优先：截图、数据库、配置、导出文件均保存在本地。
- 快捷高效：常用操作通过按钮和快捷键完成。
- 留痕清晰：时间、地点、备注、项目等信息可读且可追溯。
- 可扩展：第一版先完成可用闭环，后续扩展编辑、批量、报告和加密。
- 隐私可控：默认不联网，不上传图片，不内置云同步。

## 4. 第一版 MVP 范围

第一版目标：用户可以启动软件，设置地点，执行全屏截图，自动加时间和地点水印，保存到本地，并在历史列表中查看记录。

### 4.1 必须功能

- 全屏截图。
- 当前本地时间戳水印。
- 手动地点设置。
- 自定义项目名称。
- 水印位置选择：左上、右上、左下、右下、底部横条。
- 保存为 PNG。
- 自动保存到本地 `screenshots` 目录。
- 生成本地历史记录。
- 截图记录包含：文件路径、创建时间、地点、项目、备注。
- 从界面打开截图所在文件夹。
- 从界面复制图片到剪贴板。

### 4.2 第一版暂缓

- 区域截图透明选区。
- 当前窗口截图。
- 标注编辑器。
- 马赛克、箭头、文本标注。
- SQLite 数据库。
- PDF 报告。
- 本地加密。
- 自动更新。

这些能力会在第二阶段开始补齐。

## 5. 用户流程

### 5.1 首次使用

1. 用户打开软件。
2. 软件展示默认保存路径和示例设置。
3. 用户填写地点、项目名称。
4. 用户选择水印位置。
5. 用户点击“全屏截图”。
6. 软件截图并写入时间、地点、项目水印。
7. 软件保存 PNG 并生成历史记录。

### 5.2 日常截图

1. 用户打开软件或从托盘唤起。
2. 确认地点和项目。
3. 点击截图按钮或使用快捷键。
4. 软件保存截图。
5. 用户在历史列表查看、复制、打开文件夹。

## 6. 信息架构

主界面：

- 左侧：截图类型、地点、项目、水印设置。
- 中间：最近截图列表。
- 右侧：选中截图详情和预览。

设置：

- 默认保存目录。
- 默认地点。
- 默认项目。
- 默认水印位置。
- 时间格式。
- 图片格式。

## 7. 功能需求

### 7.1 截图

- 支持全屏截图。
- 截图前隐藏主窗口，避免截到软件本身。
- 截图后恢复主窗口。
- 多显示器第一版优先截取主显示器，后续支持选择屏幕。

验收标准：

- 点击按钮后生成 PNG。
- 图片不包含主窗口。
- 图片分辨率与屏幕截图源一致。

### 7.2 时间戳

- 默认使用系统当前时间。
- 默认格式：`yyyy-MM-dd HH:mm:ss`。
- 水印文字包含“时间”标签。

验收标准：

- 图片上可以看到时间。
- 历史记录时间与文件创建时间一致。

### 7.3 地点设定

- 用户可手动输入地点。
- 用户可保留空地点。
- 地点写入图片水印和历史记录。

验收标准：

- 修改地点后下一张截图使用新地点。

### 7.4 项目名称

- 用户可填写项目名称。
- 项目名称写入水印和历史记录。

验收标准：

- 修改项目后下一张截图使用新项目。

### 7.5 水印

- 支持四角位置和底部横条。
- 水印应有半透明背景，提高可读性。
- 水印不得覆盖过大面积。

验收标准：

- 在浅色和深色背景上均可读。
- 不同位置设置生效。

### 7.6 历史记录

- 第一版使用本地 JSON 文件存储。
- 历史记录倒序展示。
- 每条记录展示缩略图、时间、地点、项目。

验收标准：

- 重启软件后历史记录仍存在。

### 7.7 本地隐私

- 第一版不调用远程接口。
- 不上传文件。
- 本地路径可见。

验收标准：

- 没有云端账号、登录、同步入口。

## 8. 非功能需求

- 平台：Windows 10/11。
- 架构：Electron + React + TypeScript。
- 数据：本地 JSON，后续迁移 SQLite。
- 图片处理：Sharp。
- 安全：使用 preload 暴露有限 IPC，不直接在渲染层开放 Node.js。
- 性能：截图保存操作应在 2 秒内完成。
- 可维护性：主进程、preload、渲染层、类型定义分离。

## 9. 技术方案

### 9.1 技术栈

- Electron：桌面窗口、截图、系统集成。
- React：主界面。
- TypeScript：类型安全。
- Vite：开发构建。
- Sharp：水印合成、图片处理。
- electron-store：配置和历史记录。
- lucide-react：界面图标。
