# 抓个屏 WinUI 预览版 · 2026-10-13

这是 Windows App SDK / WinUI 原生迁移预览版，不是旧 Electron 正式版的自动更新。

## 本次更新

- 集成截图选区、原地标注、文字编辑、标注拖动与变换、OCR 和桌面贴图。
- 录屏支持窗口探测、自定义区域及独立控制 Dock；改进实际录制就绪确认、裁切与启停命令顺序。
- 改进跨显示器选区跟随、快捷键响应、内存裁切、异步 OCR 和媒体库刷新。
- 增加便携及 EXE 安装版本的当前用户开机启动支持。
- 修复截图工具栏线宽文字截断，统一截图工具栏和录屏 Dock 的控件样式。
- 使用统一品牌 Logo，更新标题栏、托盘、关于页、安装/卸载图标及安装向导图片。
- 补全 EXE 产品名、作者、版权和版本信息。

## 安装

- 下载 `zhuageping-winui-Setup-0.1.27-preview-20261013-logo-x64.exe`。
- 支持 Windows 10 1809 及以上版本的 x64 环境。安装到当前用户目录，无需管理员权限。
- 已包含 .NET、Windows App SDK、录屏组件、本地 OCR 引擎和三个识别模型。
- 更新前请先从托盘退出已有 WinUI 实例；请勿在录屏过程中安装更新。
- 不会默认开启开机启动。需要时可在“常规”中勾选。
- 请关闭旧版程序后再测试 F1/F2，避免两个实例争抢快捷键。
